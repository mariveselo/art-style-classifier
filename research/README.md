# Эксперименты и анализ

В этой директории сохранены материалы исследования модели классификации художественных стилей:

- `eda.ipynb` — разведочный анализ WikiArt и подготовка выборки;
- `pipeline.ipynb` — построение, обучение и сравнение EfficientNetB0, ResNet50 и Xception;
- `gradcam_demo.py` — генерация Grad-CAM-визуализаций для сохранённой модели;
- `images/` — итоговые графики и примеры визуализаций.

## Данные и результаты

EDA насчитывает 62 434 изображения в десяти наиболее представленных классах
исходной коллекции. Пайплайн обучения работает с подготовленной выборкой из
60 565 доступных изображений: 48 447 в директории train (включая выделяемую
validation-часть) и 12 118 в отдельной test-директории. Поэтому эти значения
описывают разные этапы подготовки данных и не должны совпадать.

Итоговая модель — Xception. На отдельной тестовой директории получены следующие метрики:

| Метрика | Значение |
|---|---:|
| Accuracy | 0.6064 |
| Top-3 Accuracy | 0.8954 |
| Macro-F1 | 0.6196 |

## Воспроизводимость

В `pipeline.ipynb` training и validation создавались двумя вызовами
`image_dataset_from_directory` с одинаковым `seed`, но разными значениями
`shuffle`. В зависимости от версии Keras такой способ разбиения может приводить
к пересечению подмножеств. Поэтому сохранённые validation-кривые следует
рассматривать как диагностические графики исходного эксперимента, а не как
независимую оценку обобщающей способности.

Тестовая выборка загружалась из отдельной директории и не участвовала в этом
разбиении. Приведённые выше тестовые метрики сохранены без пересчёта. Для нового
запуска train и validation следует получать одним вызовом с `subset="both"`
либо использовать заранее сформированные непересекающиеся директории.

Ноутбуки содержат пути, ориентированные на Google Colab и Google Drive. Они
сохранены как журнал экспериментов; для повторного запуска пути к данным и
каталогам результатов нужно задать в первых ячейках.

## Grad-CAM

Скрипт использует модель и метаданные из директории `model/` по умолчанию:

```bash
python research/gradcam_demo.py path/to/images
```

Другие пути можно передать через `--model`, `--metadata`, `--output-dir` и
`--sheet`. Полный список параметров выводится командой:

```bash
python research/gradcam_demo.py --help
```
